📌 Visão geral do projeto
--------------------------------------------------------------------------------------------------
Este projeto lógico foi desenvolvido dentro do curso da DIO, com o intuito de replicar e refinar a modelagem do projeto lógico de banco de dados para o cenário de e-commerce, utilizando a ferramenta MySQL.

---------------------------------------------------------------------------------------------------
🎯 Objetivos
---------------------------------------------------------------------------------------------------
• definições de chave primária e estrangeira, assim como as constraints presentes no cenário modelado 

• Elaborar Script SQL para criação do esquema do banco de dados    

• Recuperar simples com SELECT Statement

• Criar Filtros com WHERE Statement

• Criar expressões para gerar atributos derivados

• Definir ordenações dos dados com ORDER BY

• Definir condições de filtros aos grupos – HAVING Statement

• Criar junções entre tabelas para fornecer uma perspectiva mais complexa dos dados
